# Past event images

Each past event has its own dated folder. The website displays the `cover.png`,
`cover.jpg`, or `cover.jpeg` file referenced by the event pages.

To change an event photo, replace its existing `cover` file with a new image
using the same filename and extension. Keep one displayed cover image per event.
Where available, the original event flyer is preserved as `poster.png`.

For future events, create a folder named `YYYY-MM-DD-event-name`, add its cover
image, and update the image path on both event pages.
